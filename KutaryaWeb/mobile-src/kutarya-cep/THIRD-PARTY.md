# Üçüncü taraf bileşenler

Uygulama: OkHttp 4.12.0, Okio 3.6.0 (Apache-2.0); Kotlin standart kütüphanesi (Apache-2.0; bağımlılık geçişli, uygulama kodu Java). OkHttp Kotlin ile yazıldığı için APK'da Kotlin runtime bulunması, projenin Kotlin ile geliştirildiği anlamına gelmez.
