# 401 ile 403 farkı

**Hata mesajı:** `401 Unauthorized / 403 Forbidden`
**Teknoloji:** Web / HTTP
**Sınıf:** Kimlik

401 kimlik doğrulamanın eksik veya geçersiz, 403 ise kimlik bilinse de yetkinin yetersiz olduğunu anlatır.

## Olası nedenler

- Token yok veya süresi dolmuş
- Yanlış audience/issuer
- Rol veya kaynak yetkisi eksik
- Cookie isteğe eklenmiyor

## Teşhis sırası

1. Network isteğinde kimlik bilgisinin gönderildiğini kontrol edin.
2. Token süresi ve hedefini sunucuda doğrulayın.
3. Sunucu yetki günlüğünde reddedilen kuralı bulun.

## Düzeltme yaklaşımları

- 401 durumunda yeniden kimlik doğrulama akışı kurun.
- 403 durumunda rolü değil gereken kaynak iznini kontrol edin.
- Hassas ayrıntıyı istemci hata mesajında açığa çıkarmayın.
